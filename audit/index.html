Claude Code operating-model audit

A small Georgia company finds software teams that already use Claude Code by looking for a CLAUDE.md file in one of their public repositories. Then it reads that file and tells them what it actually enforces and what it only hopes to enforce. The Claude Code sessions wrote this page; an engineer reviewed it and decided it could ship.

What the problem is

A CLAUDE.md rule written in prose is a suggestion. Claude Code reads it, but nothing stops a session from skipping it under pressure. The steward-kit hooks exist to close that gap. There are twelve: three deny a bad tool call before it runs, one flags a write outside git right after it, and eight never block, they remind, re-inject or log. Most teams have the prose. Few have the hooks wired up.
