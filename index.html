A working operating model for Claude Code sessions

Rules that were only prose kept getting skipped under pressure. Each one that mattered became a hook or a check. This is the result, packaged so you can try it on your own machine.

What it is

One setup, described and shipped as files. It covers a contract file the agent reads first, a knowledge base of notes with size caps, a memory format, two agent definitions, tiering rules for which model does which job, hooks that enforce the rules mechanically, watchers that carry their own stop condition, and long-lived sessions that survive a restart.

It was built by an engineer and his Claude Code sessions over several months, on a homelab and a few side projects. The sessions wrote this site. The engineer sets direction, reviews results and decides what ships.

It is one person's working style, tested by smoke runs and by daily use. It has not been tested on many other machines, and the pages below say where the gaps are.
